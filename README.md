Phần Mềm Quản Lý Thư Viện

Ứng dụng quản lý hoạt động mượn - trả và tra cứu sách trong thư viện, được xây dựng theo mô hình 3 lớp nhằm phục vụ công tác quản trị và lưu trữ dữ liệu chính xác.

1. Công nghệ sử dụng
Ngôn ngữ: C# (.NET)
Giao diện: Windows Forms (WinForms)
Cơ sở dữ liệu: Microsoft SQL Server
Kiến trúc: Mô hình 3 lớp (3-Tier Architecture)

2. Các chức năng chính
Quản lý danh mục sách: Thêm, sửa, xóa thông tin đầu sách, tác giả, thể loại và số lượng tồn.
Quản lý độc giả: Cấp và quản lý thẻ thư viện, thông tin liên hệ độc giả.
Mượn - Trả sách: Lập phiếu mượn, ghi nhận ngày hẹn trả, tính hạn và quản lý tiền phạt quá hạn.
Báo cáo & Thống kê: Thống kê số lượng sách đang cho mượn, số lượt mượn theo thời gian và danh sách sách trễ hạn.
